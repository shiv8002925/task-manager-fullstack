# 🚀 Task Manager (Full Stack)

A full stack web application where users can manage projects and tasks with role-based access.

---

## ✨ Features

- 🔐 User Authentication (Signup/Login)
- 📁 Project Management
- 📋 Task Creation & Assignment
- 🔄 Mark Task Done / Pending
- 📊 Dashboard (Total, Completed, Pending tasks)

---

## 🛠 Tech Stack

### Frontend
- React.js
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MySQL (Sequelize ORM)

---

## ⚙️ How to Run Locally

### 🔹 Backend

```bash
cd backend
npm install
node server.js
